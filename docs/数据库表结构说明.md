## 九、核心关系图

```
persons (人员主表)
  ├── person_aliases (别名, 1:N)
  ├── person_group_memberships (分组归属历史, SCD2)
  ├── person_specialty_assignments (专项分配历史, SCD2)
  └── staff_assignments (员工分配历史)

groups (行政分组)
  ├── group_leadership_history (组长变更, SCD2)
  └── person_group_memberships (成员归属, SCD2)

specialties (业务专项)
  ├── specialty_leadership_history (负责人变更, SCD2)
  └── person_specialty_assignments (人员分配, SCD2)

service_tickets / refunds / cs_records (业务原始数据)
  └── 通过 SN (序列号) 跨表关联
      └── operator → person_aliases → persons (操作员匹配)
```

## 十、索引策略

### 10.1 时间字段索引

所有业务原始数据表的时间字段均建索引，支持时间范围查询：
- `CREATE INDEX ix_<table>_<time_field> ON <table> (<time_field>)`

### 10.2 复合索引

SCD Type 2 历史表的 `(entity_id, is_current)` 复合索引加速"查当前归属"查询。

### 10.3 SCRM 复合索引

- `(person_id, start_time)`：按人员查会话
- `(session_type, start_time)`：按类型查会话
- `(question_type_name, start_time)`：按问题类型查会话
