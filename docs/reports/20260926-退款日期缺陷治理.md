## 二、30b 设计裁决 + 验收清单

**设计（30b 2026-09-26）**：
1. `26/0920` → 严格形态 `YY/MMDD`，月/日合法性由 `datetime` 构造器把关；非标形态（`26/09/20`、`2026/0920`）不认
2. 空日期 → 上下邻近行可解析日期都存在且**同一天**才填充；取上一行原始字符串；标记键 `_register_time_filled_from_neighbor`
3. 证据不足不猜——单侧缺失/异天不填，走既有 dropped+拒收流程

**验收清单 A1-A4**：

| 项 | 状态 | 证据 |
|---|---|---|
| A1 空日期行填充为上一行日期 | ✅ pass | `_fill_empty_register_time` 单元测试：同天填充/异天不填/单边缺失不填 |
| A2 `26/0920` 解析为 2026-09-20 | ✅ pass | probe 工具：`26/0920`→2026-09-20 UTC 16:00（= 北京 00:00） |
| A3 `26/09/20`/`2026/0920` 非标形态为 None | ✅ pass | audit/入库两侧均不认，pd.to_datetime 兜底也不认 |
| A4 既有解析逻辑回归不变 | ✅ pass | 冻结语料重算 matched=4213 不变 |

## 三、修复方案

### 3.1 入库侧日期解析（`upsert/_core.py`）

```python
# 新增紧凑格式解析器
_COMPACT_YY_SLASH_RE = re.compile(r"^(\d{2})/(\d{2})(\d{2})$")

def _try_compact_date(val: Any) -> datetime | None:
    # ... 8 位 YYYYMMDD 分支不变
    m = _COMPACT_YY_SLASH_RE.match(s)
    if m:
        dt = datetime(2000 + int(m.group(1)), int(m.group(2)), int(m.group(3)))
        return dt.replace(tzinfo=_TZ_CN).astimezone(timezone.utc)
```

### 3.2 审计侧日期解析（`refund_data_audit.py`）

```python
m2 = re.match(r'^(\d{2})/(\d{2})(\d{2})$', s)
if m2:
    dt = datetime(2000 + int(m2.group(1)), int(m2.group(2)), int(m2.group(3)))
    return dt
```

### 3.3 空日期邻近填充（`manual_refund_sync.py`）

新增 `_fill_empty_register_time(rows_raw) -> int`：
- 规则① 行需有业务字段值（模板噪音行不填）
- 规则② 上下最近可解析日期都存在且同一天才填
- 规则③ 取上一行原始字符串 + 标记键 `_register_time_filled_from_neighbor`
- 调用点插在 `sync_manual_refunds_from_payload` 的输入校验之后、`_clean_row` 之前
