## 五、方法与局限

- 「死表」判据 = 模型存在但 models/alembic 外零引用 **且** 生产 0 行；本台账未发现严格意义的死表（最低也有 1 个引用文件）。
- 引用扫描按模型类名精确匹配，经 SQL 字符串/`text()` 直接访问的表可能漏计；`ticket_action_logs`（0 refs 但 227MB 数据与 5.6M idx_scan）即属此类——判定以生产扫描统计为准。
- seq_scan 高不必然缺索引：小表（<11MB）全扫是最优计划，本台账仅将「大表 + 高频全扫」列为问题（唯一命中：`cs_records`）。
