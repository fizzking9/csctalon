## 任务

给 #152 分级框架补「收集→评审→人工迭代」反馈回路：standard 校验缺失清单落库 `ai_reports.latest_missing`，周期任务每日聚合近 7 天生成「提示词健康报告」落 `system_events`，报告指出高频缺失维度并给模板/提示词/feed 三层建议（**只出建议，不自动改**）。

## 实现步骤

1. **迁移**：`ai_reports` 加 `latest_missing JSONB NULL`（Alembic 单 head，新建版本前 `grep alembic/versions` 确认 revision id 唯一）
2. **收集层写回**：`ai.py` L1/L2 standard 分支在 `check_dimensions` 后调 `record_latest_missing(_match_db, report.id, missing)`（两处同规）；`ai_report_service.py` 新增该函数（参数化 `UPDATE` + **直接 commit**，失败 rollback+log）
3. **评审层服务**：新建 `ai_feedback_service.py`，实现 `build_health_report`（五段输出）+ `run_daily_health_report`（单飞锁 + 落 system_events）+ `check_daily_health_report_idle`（8-23 点 + 当日幂等）+ `_to_markdown`
4. **调度接入**：`cache_warmer.start_warm_loop._loop` 每 60s 空闲循环追加 `check_daily_health_report_idle`（`asyncio.to_thread`，不占事件循环）
5. **测试 + 部署 + 凭证**：单测 + ruff → push → 生产 `upgrade.sh --git` → docker exec 实测 → 凭证关单

## 输入 / 输出契约

### record_latest_missing（收集层写回）

```python
def record_latest_missing(db: Session, report_id: int, missing: list) -> None:
    """missing=[] 已校验且齐全; NULL/JSON-null=未校验(评审时重算兜底)。直接 commit。"""
```

### build_health_report（评审层输出五段）

| 段 | 字段 | 说明 |
|---|---|---|
| window | start/end/days/generated_at | 近 7 天北京时间窗口 |
| overall | questions/by_mode/hits/hit_rate/live_ratio | `hit_rate=(full+section)/n`；`live_ratio=live/n`，≥0.5 → 提示词层告警 |
| templates | code/name_cn/period/detail_level/has_dims/snapshots/matched/checked_count/with_missing | 窗口内公共快照；checked 按 `jsonb_typeof='array'` |
| missing_top | dim/count（TopN=8） | 已校验聚合 + 历史快照按模板维度重算兜底 |
| top_live_qs | question/start/end/count | 同问句+同窗口 live≥2 次 |
| suggestions | str[] | 三层建议：feed 供给（缺失维度）/ 模板层（快照 0 命中）/ 提示词层（live 占比高 / 高频未答好） |

### 周期任务（落 system_events）

- `action='ai_feedback_health_report'`，`detail=_to_markdown(data)`（含 `## AI 提示词健康报告` / `### 三、缺失维度 TopN` / `### 五、迭代建议` 锚点）
- 有缺失/高频/live 占比高 → `status=partial, level=warning`，否则 `success/info`

## 约束

1. 表结构变更必须走 Alembic 迁移（禁止绕过）
2. SQL 一律 `text()` + 绑定参数；`"start"/"end"` 是 PostgreSQL 保留字，手写 SQL 必须 `""` 引号化（#116 教训）
3. 时间窗口以北京时间计：`created_at AT TIME ZONE 'Asia/Shanghai'`，`since_ts` 用 `%Y-%m-%dT00:00:00+08:00`
4. **JSONB 口径**：`latest_missing` 语义为「数组=已校验（空=齐全）、NULL/JSON-null=未校验」；聚合 SQL 一律 `jsonb_typeof(latest_missing)='array'` 守卫——SQLAlchemy 把 Python `None` 存为 JSON null 而非 SQL NULL，`jsonb_array_length('null')` 会报 scalar 错
5. `record_latest_missing` 必须直接 commit（standard 缺维度走补算路径时命中会话最终不 commit，否则永不落库）
6. 周期任务进程级单飞锁 + 当日幂等（防 idle 循环每分钟重复生成）
7. **不自动改提示词/feed**：服务只输出建议文案，禁止对 `_SYSTEM_PROMPT`/`_EXTRACT_SYSTEM`/`_build_feed` 的任何写入

## 禁止事项

1. 禁止无工单开发（#153 已建）
2. 禁止绕过 Alembic 直接改表
3. 禁止 f-string 拼 SQL、硬编码密钥/内网 IP
4. 禁止自动修改提示词（`_SYSTEM_PROMPT` 铁律是全树根）
5. 禁止 `console.log`/裸 `print`（后端用 logger）
