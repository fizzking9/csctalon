# 趋势视图时间粒度切换(日/周/月)

## Context(为什么做)

退款现金流趋势(堆积)、提现池子水位等趋势类预设视图,时间粒度在 seed 里写死 `day`。当时间范围拉长到周/月级别时,按日聚合点数过多(30~90+ 点),趋势规律不清。后端 `_apply_time_grain` 已支持 day/week/month/quarter/year(日期压紧那次刚改过),但**没有运行时覆盖入口** —— 预设视图无法在浏览时切换粒度。

**目标**:为趋势类视图(单视图页 + 看板页)增加 日/周/月 选择器,默认按日,用户可手动切换,长周期看周/月聚合更清晰。

**用户已确认**:选择器加在 ViewRender + DashboardView 两处;默认按日(手动切换)。

> 注:用户问"超过一周时是不是可以选择"——理解为"长周期下应能切周/月",即手动可切;
> 不自动随范围切换(避免用户预期外的图突变),后续如需"按范围智能默认"可再加。

## 明确不做(避免过度)

- **不加 季度/年 选项**:趋势图用 周足矣覆盖长周期;季度/年点数过少意义不大(ViewBuilder 自助构建里仍保留全选项)
- **不做"按范围智能默认"**:用户已选默认按日手动切;智能默认逻辑后续可加
- **不改 ViewBuilder**:它的粒度选择器(L79-84)是构建自定义视图时用的,属另一场景,保持原样
- **不加后端 time_grain 白名单校验**:前端只发 day/week/month,引擎 `_apply_time_grain` 对未知 grain 走默认按日,安全
