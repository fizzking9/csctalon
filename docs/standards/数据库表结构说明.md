# 数据库表结构说明

> 版本：v1.1 · 日期：2026-08-26
> 数据库：PostgreSQL 15
> 总表数：86 张
> 关联代码：[backend/app/models/](../backend/app/models/)
> 说明：本版以代码为准全面重写，修正表数（56→86）、各表时间字段、补全缺失表、删除幽灵表 `recharges`。

## 一、表分类总览

| 分类 | 表数 | 说明 |
|---|---|---|

| 维度主数据 | 8 | 人员/商户/设备/分组/专项/数据源等维度 |

## 九、核心关系图

```
persons (人员主表)
  ├── person_aliases (别名, 1:N)
  ├── person_group_memberships (分组归属历史, SCD2)
  ├── person_specialty_assignments (专项分配历史, SCD2)
  └── staff_assignments (员工任职历史, SCD2)

groups (行政分组)
  ├── group_leadership_history (组长变更, SCD2)
  └── person_group_memberships (成员归属, SCD2)

specialties (业务专项)
  ├── specialty_leadership_history (负责人变更, SCD2)
  └── person_specialty_assignments (人员分配, SCD2)

service_tickets / refunds / cs_records / wallet_withdrawals (业务原始数据)
  └── 通过 SN (序列号) 跨表关联
      └── operator → person_aliases → persons (操作员匹配)

refunds (退费单) ── 四路经营口径聚合 ──┐
wallet_withdrawals (钱包提现)           ├── refund_wide (退费宽表, 聚合加速)
shanmao_refunds (山猫退款)              │
manual_refunds (手动退款登记) ──────────┘
merchant_refunds (商户号款项, v1.0 快照) ── 保留供 matcher/wide 关联, 不再作对账取数
refund_record_reports (退款记录报表) ── 对账基准 E (2026-09-05 v1.1 起, 不参与经营四路累加)
  └── 逐笔勾稽 A/B/C/D → matched/未登记; D 路 op_time 缺失按水单回填(auto_filled)
bms_orders (订单管理台账) / return_trackings (退货跟踪) / device_flow_usage (设备月流量)

devices (设备主表, 领域核心)
  ├── device_tags ─ device_tag_rel ─ devices (多对多)
  ├── device_tag_batches (专项标签批次, 1:N)
  ├── device_combos (设备套餐, 1:N)
  └── refunds/service_tickets/wallet_withdrawals/merchant_refunds (通过 SN)


users ── wechat_accounts (微信身份绑定, 1:N) ── wechat_registrations (待审批)
      └── todo_items/tasks/reports/measures/incidents (负责人/创建人 FK)
```

## 十、索引策略

### 10.1 时间字段索引

所有业务原始数据表的时间字段均建索引，支持时间范围查询：
- `CREATE INDEX ix_<table>_<time_field> ON <table> (<time_field>)`

### 10.2 复合索引

SCD Type 2 历史表的 `(entity_id, is_current)` 复合索引加速"查当前归属"查询。

### 10.3 SCRM 复合索引

- `(person_id, start_time)`：按人员查会话
- `(session_type, start_time)`：按类型查会话
- `(question_type_name, start_time)`：按问题类型查会话

### 10.4 其他关键索引

- `merchant_refunds`：`(merchant_id, trade_time)`、`merchant_order_no`、`device_no`（对账查询）
- `refund_wide`：`device_sn`、`created_at_raw`、`operator`、`status`（四路看板聚合）
- `wallet_withdrawals`：`(account_id, op_type, op_time, operator, op_amount, device_sn)` 业务唯一约束
- `service_tickets`：`handler`、`register_time`、`status`（人员绩效/时效查询）
- `manual_refunds`：`register_time`、`device_sn`、`quality_status`、`(register_order, amount)` 业务唯一约束
