# 投诉数据接入说明(315 / 卡商)

> 更新: 2026-09-01
> 入口: 数据采集 → 「投诉接入」

投诉登记数据(315外部投诉 / 卡商群投诉)支持**三种接入方式**, 在「数据采集 → 投诉接入」页统一管理, 顶部有**采集方式开关**选择启用哪些。三种方式数据汇入同一投诉台账并按设备SN关联工单, 指纹去重保证重复数据不会累积。

---

## 〇、三源归类口径(2026-09-01 用户确认)

投诉在全系统统一归为**三源**: **内部投诉 / 商户号投诉 / 外部投诉**。归类规则:

| 三源 | 来源 | 判定 |
|---|---|---|
| **内部投诉** | service_tickets 工单 | `service_item` = 商品投诉 / 服务投诉 |
| **商户号投诉** | service_tickets 工单 | `service_item` = 微信投诉(仅工单) |
| **外部投诉** | service_tickets 工单 + 两张补充表 | 工单 `service_item` 含 12315/工信部/消协/监督局/市场监管 等外部平台关键词; **315外部投诉(external_complaints)与卡商群投诉(card_complaints)全部计入外部投诉桶**; 工单未标注/其它兜底归外部投诉 |

> 说明:
> - 卡商群投诉虽数据形态独立(卡商群内投诉), 但关联的工单均为外部投诉类(工信部/12315等), 故**归入外部投诉**。
> - 315/卡商两张补充表在明细与统计中作为"补充数据源"独立展示(`supplementary`), 计数上计入对应三源桶(315与卡商均→外部投诉)。
> - 涉及实现: `backend/app/api/v1/complaints.py`(`/summary` `/detail` `/analysis`)、`backend/app/services/analytics.py`(`_complaint_source_type_case` 工单三源判定)。

| 方式 | 适用场景 | 需前置 |
|---|---|---|
| ① 主动监测(腾讯文档) | 系统自己定时读共享文档, 最省心 | 注册腾讯文档开放平台应用 |
| ② 定时推送(WorkBuddy等) | 沿用外部工具中转 | 服务器配置 WORKBUDDY_SYNC_TOKEN |
| ③ 文件导入 | 临时/一次性补数据 | 无 |

---

## 一、采集方式开关

「投诉接入」页顶部可分别开关三种方式:

- **主动监测** 关闭 → 系统停止定时读取共享文档。
- **定时推送** 关闭 → 推送接口直接返回 503(即使 token 已配置)。
- **文件导入** 恒可用(手动操作, 无开关)。

> 建议: 「主动监测」与「定时推送」同时开启时, 同一批投诉会以两种来源重复入库(去重不会产生脏数据, 但日志会有两条), 建议只保留一种常用方式。

---

## 二、主动监测(腾讯文档)使用步骤

### 1. 注册开发者应用(一次性, 个人即可)

1. 打开 [腾讯文档开放合作平台](https://docs.qq.com/open/developers/), 用微信/QQ 登录注册开发者(个人主体即可, 免费)。
2. 创建第三方应用, 等待审核(结果邮件通知)。
3. 审核通过后获取 **ClientID / ClientSecret**。
4. 在应用后台配置**回调域名**为系统访问地址(生产建议 HTTPS, 腾讯文档接口仅支持 HTTPS 请求)。

### 2. 系统内配置(数据采集 → 投诉接入 → ① 自动监测)

1. **凭证**: 填 ClientID / ClientSecret(Secret 仅保存不回显), 回调地址可留空(自动按当前访问地址生成)。
2. **授权**: 点「前往授权」→ 新窗口微信/QQ 扫码同意 → 自动回跳完成授权(系统自动轮询等待授权结果)。
3. **文档配置**: 粘贴共享表格链接(如 `https://docs.qq.com/sheet/xxxxx` 或分享短链), 可指定 315 / 卡商 的 Sheet 名(留空自动取第一张表), 设轮询间隔(默认 20 分钟), 开启「自动同步」。
4. 点「立即同步一次」验证数据入库, 之后系统按间隔自动监测。

### 3. 查看状态

- 页面下方「最近同步」展示上次同步时间 / 315与卡商行数 / 状态 / 错误信息。
- 「同步日志」列出最近同步记录(所有来源)。

## 三、定时推送(WorkBuddy / 外部工具)

### 1. 服务器开启

在 `.env` 配置后重启后端:

```
WORKBUDDY_SYNC_TOKEN=<openssl rand -hex 32 生成>
```

### 2. 推送规范(简版)

```
POST {系统地址}/api/v1/sync/complaints/push
Authorization: Bearer <WORKBUDDY_SYNC_TOKEN>   (或 X-Sync-Token 头)
Content-Type: application/json

{
  "source_file": "315投诉处理登记表.xlsx",
  "external_complaints": [ { "投诉日期": "2026-08-19", "投诉人": "张三", "投诉设备号": "67482454178206", ... } ],
  "card_complaints":     [ { "投诉日期": "2026-08-19", "投诉群": "卡商A群", "设备号": "67482454178206", ... } ]
}
```

- 建议每 20 分钟检查文件, **变化才推送**(全量推文件全部行即可, 系统按指纹去重)。
- 字段名用 xlsx 中文列名或英文字段名均可。
- 完整字段映射与清洗规则见 [docs/workbuddy数据同步接入规范.md](workbuddy数据同步接入规范.md)。

### 3. 查看

「投诉接入 → ② 定时推送」页面展示推送地址、token 是否已配置、最近推送日志。

---

## 四、文件导入(手动上传)

「投诉接入 → ③ 文件导入」或「数据采集 → 文件上传」:

1. 选择数据类型(外部投诉 或 卡商群投诉)与文件(xlsx/csv)。
2. 预览列名映射(自动建议, 可调整)。
3. Diff 复核(新增/已存在/异常行)。
4. 确认导入, 完成后自动按 SN 关联工单。

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 「前往授权」按钮置灰 | 未保存 ClientID/Secret, 先完成凭证配置 |
| 授权后回跳提示失败 | 回调地址与开放平台登记的不一致, 检查回调域名 |
| 同步报「访问令牌已过期且无刷新令牌」 | 授权超 1 年或 refresh_token 失效, 重新授权 |
| 同步报 503 | 推送方式已关闭或 token 未配置, 检查采集方式开关 / .env |
| 「无法从链接解析文档ID」 | 链接非腾讯文档分享链接, 或链接已失效 |

同步明细可在「决策看板 → 投诉专项 → 补充明细」查看。
