## 落地建议（按你的两阶段路线）

**第一阶段（统计分析 + 管理干预）**
- 数据底座/报表：DataEase（或 Metabase）+ MySQL/ClickHouse，把接待量、工单、退款、投诉四张事实表做成日报看板
- 字段建模参考：osTicket/UVdesk 的自定义字段（投诉类型、退款原因）、CRMEB 的售后/退款/会员充值表结构
- 客服绩效指标参考：Chatwoot 的 CSAT/agent 报表、智齿/芝麻类产品的"工作量统计指标口径"（创建工单数、平均处理时长、3 分钟响应率、未回复率等）

**第二阶段（夜间批量分析 + 小模型预测干预）**
- 编排：Dify 工作流 或 直接 Python 批处理（Airflow 调度夜间任务）
- 分类/抽取模型：PaddleNLP UIE 或 Qwen-8B LoRA 微调（LLaMA-Factory），输入=话题类型+投诉文本摘要+退款记录+操作日志，输出=客户风险分+干预建议清单
- 情绪/升级预警：参考 sentiment_monitor 的负面分级预警机制
